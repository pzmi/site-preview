# 0053. Conformance harness: an explicit ITF replay path; Quint Connect not adopted yet

Date: 2026-10-12

## Status

Accepted (owner, 2026-10-14)

## Context

foundation.md §6.3 names Quint Connect as the first-choice generator/replay integration and
also requires a separately tested, explicit ITF replay path for committed regression traces,
with model hooks independent of the harness library. FORMAL-04 evaluates it against
`lifecycle.qnt` (ADR 0052). `quint-connect` 0.1.2 (Apache-2.0, published 2026-05-25) is
still the latest version on crates.io. It was tried in a scratch crate outside the
workspace, with a toy driver over `serverStep`:

- It runs a bare `quint` from `PATH` with no backend option, so Quint 0.33.0 picks its Rust
  evaluator, which it downloads from GitHub at first use. The sandbox proxy refuses that
  download (403) and ADR 0052 forbids it anyway (an unpinned binary outside every lockfile).
  The run failed with "Quint returned non-zero code". With a `PATH` shim that runs the
  locked `formal/node_modules/.bin/quint` with `--backend typescript` appended, the same
  test passed: the `switch!` macro decoded `startServer(bindOk, watcherOk)` from
  `mbt::nondetPicks` and the state comparison worked.
- It only replays traces it generates into a temporary directory: there is no public API to
  replay a committed ITF file (its trace iterator is crate-private), which §6.4's
  regression corpus needs.
- The seed is random by default and read with `option_env!("QUINT_SEED")`, so repeating a
  run means recompiling; one driver value is reused across all traces of a run.
- A divergence is an `anyhow` error, "State invariant failed"; the step index and the diff
  are printed only with `QUINT_VERBOSE` set, so a negative control cannot assert the exact
  step (FORMAL-08).
- Its macros expand to `anyhow::...`, so the using crate must depend on `anyhow` directly,
  and it pulled 115 packages into the scratch lockfile (`itf`, `serde_with`, `schemars`,
  `rand`, `colored`, `similar`, `tempfile`, ...).

## Decision

- Do not adopt `quint-connect` now. It is not a workspace dependency.
- `preview-conformance` (test only) owns the explicit replay path, with `serde_json` as its
  only new dependency: `itf.rs` decodes the ITF subset Quint writes (`#bigint`, `#tup`,
  `#set`, `#map`, records, `{tag, value}` variants, lists; anything else is refused with a
  path); `replay.rs` defines `Driver { type Obs; apply(action, params); observe() }` and
  `replay(trace, driver, project_expected)`, comparing after every ITF state, `init`
  included; `report.rs` formats the `Divergence` (model, seed, trace id, step, action,
  params, expected, actual, line diff).
- Drivers decode their own parameters from `Params` (`mbt::nondetPicks` with `Some(v)`
  unwrapped and `None` dropped). Nothing in a driver names a harness library, so adopting
  Quint Connect later means an adapter from its `Step` to `Driver::apply`, not a rewrite.
- Traces are generated by xtask with the locked Quint and `--backend typescript --mbt`; the
  seed comes from the generating command or the corpus manifest, since ITF does not record
  it.
- Revisit when Quint Connect can run a configured Quint command (or pass `--backend`) and
  replay committed ITF files with a reportable step index.

## Consequences

- The replay path is ours to maintain: a narrow decoder and a small LCS diff, unit-tested
  against `formal/traces/regression/itf-decoder-sample.itf.json` (seed 11, five
  `serverStep` steps of `lifecycle.qnt`) and a toy driver.
- Quint's ITF carries a creation date in `#meta`, so FORMAL-09's byte-for-byte freshness
  check must normalize `#meta.description` and `#meta.timestamp`; the rest of the file is
  identical across runs with the same seed.
- FORMAL-05 to FORMAL-08 implement `Driver` per model and assert on `Divergence` fields;
  `replay` returns `Box<Divergence>`, whose fields read the same through the box.
